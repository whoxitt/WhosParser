# 🔎 Telegram NFT Parser Bot

Бот для поиска пользователей с Telegram NFT подарками в чатах.

## 📋 Возможности

- ✅ Подключение Telegram-аккаунта через номер телефона (без готовой сессии)
- ✅ Автоматическое сохранение и восстановление сессии при перезапуске
- ✅ Парсинг участников из ваших чатов
- ✅ Поиск пользователей с NFT подарками
- ✅ Фильтрация по неулучшенным подаркам
- ✅ PostgreSQL база данных

## 🚀 Деплой на bothost.ru

### 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather)
2. Создайте бота командой `/newbot`
3. Скопируйте полученный токен

### 2. Узнайте свой Telegram ID

1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Скопируйте ваш ID

### 3. Получите Telegram API credentials

1. Зайдите на [my.telegram.org/apps](https://my.telegram.org/apps)
2. Создайте приложение
3. Скопируйте `API_ID` и `API_HASH`

### 4. Настройте переменные на bothost.ru

Перейдите в настройки вашего проекта на bothost.ru и добавьте следующие переменные окружения:

```bash
# Обязательные переменные
BOT_TOKEN=your_bot_token_from_botfather
OWNER_ID=your_telegram_id
DATABASE_URL=postgres://user:password@host:5432/dbname

# Telegram API (для парсера)
TG_API_ID=your_api_id
TG_API_HASH=your_api_hash
```

**📌 Важно:** `DATABASE_URL` будет автоматически создан bothost.ru при подключении PostgreSQL базы данных.

### 5. Загрузите код

1. Переименуйте файлы:
   - `bot_new.py` → `bot.py`
   - `database_pg.py` → `database.py`
   - `keyboards.py` → `keyboards.py` (уже новый)
   - `ui_messages.py` → `ui.py`
   - `requirements_new.txt` → `requirements.txt`
   - `parsing/telegram_client_new.py` → `parsing/telegram_client.py`

2. Загрузите проект на bothost.ru

3. В настройках укажите команду запуска:
   ```bash
   python bot.py
   ```

## 📱 Использование

### Первый запуск

1. Запустите бота командой `/start`
2. Нажмите **⚙️ Админка**
3. Нажмите **📱 Подключить аккаунт**
4. Введите номер телефона в формате: `+79991234567`
5. Получите код в Telegram
6. Введите код **через пробелы**: `1 2 3 4 5`
7. ✅ Аккаунт подключён!

### Парсинг

1. Нажмите **🔎 Парсер**
2. Выберите режим поиска:
   - 🎁 Любые NFT
   - 💎 Только неулучшенные NFT
3. Укажите количество профилей для проверки
4. Бот начнёт поиск и будет присылать найденные подарки

## 🗄️ База данных

Бот использует PostgreSQL с следующими таблицами:

- `parser_session` - сохранённая сессия Telegram аккаунта
- `parser_chats` - список ваших чатов
- `parser_users` - найденные пользователи
- `parser_gifts` - найденные подарки
- `parser_scan_state` - состояние сканирования

## 🔍 Как работает парсер

1. **Подключение аккаунта**: Бот запрашивает ваш номер телефона и код подтверждения
2. **Сохранение сессии**: StringSession сохраняется в PostgreSQL базу данных
3. **Автовосстановление**: При перезапуске бот автоматически восстанавливает сессию
4. **Получение списка чатов**: Бот загружает все ваши группы и каналы через Telethon
5. **Парсинг участников**: Для каждого выбранного чата бот получает список участников
6. **Проверка NFT**: Для каждого участника бот через MTProto API проверяет наличие NFT подарков
7. **Фильтрация**: В режиме "неулучшенные" показываются только подарки, которые можно улучшить
8. **Сохранение результатов**: Все найденные пользователи и подарки сохраняются в БД

## ⚠️ Важные моменты

- **Скорость парсинга**: Бот работает медленно с паузами между запросами, чтобы избежать FloodWait от Telegram
- **Сессия сохраняется**: При перезапуске бота не нужно вводить код повторно
- **Только администратор**: Бот доступен только пользователю с ID указанным в `OWNER_ID`
- **Приватность**: Все данные хранятся в вашей базе данных

## 🛠️ Устранение проблем

### Бот не запускается
- Проверьте правильность `BOT_TOKEN`
- Убедитесь что `DATABASE_URL` корректный
- Проверьте логи на bothost.ru

### Не могу подключить аккаунт
- Проверьте `TG_API_ID` и `TG_API_HASH`
- Убедитесь что вводите код через пробелы: `1 2 3 4 5`
- Проверьте что номер телефона в международном формате: `+79991234567`

### Парсер не находит подарки
- Проверьте что выбраны нужные чаты в настройках
- Убедитесь что в чатах есть участники с NFT
- Попробуйте увеличить лимит проверяемых профилей
