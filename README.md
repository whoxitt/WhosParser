# NFT Parser Bot

Telegram бот для поиска пользователей с NFT подарками в чатах.

## Возможности

- Многопользовательский режим (несколько пользователей могут парсить одновременно)
- Система подписок через TON (5 TON за 24 часа)
- Автоматическая проверка платежей через TON Console API
- Рандомный выбор чатов и пользователей (без повторов между юзерами)
- Лимит: 10 пользователей с NFT за один запуск
- Кулдаун: 5 минут между запусками
- Админ-панель с полным управлением

## Установка

### 1. Клонировать репозиторий
```bash
git clone <repository_url>
cd WhosParser-main
```

### 2. Установить зависимости
```bash
pip install -r requirements.txt
```

### 3. Настроить переменные окружения

Создайте файл `.env` со следующими переменными:

```env
# Токен бота от @BotFather
BOT_TOKEN=your_bot_token_here

# ID владельца бота (ваш Telegram ID)
OWNER_ID=your_telegram_id

# PostgreSQL база данных
DATABASE_URL=postgresql://user:password@host:port/database

# TON Console API
TON_API_KEY=your_ton_console_api_key
TON_WALLET_ADDRESS=your_ton_wallet_address
```

### 4. Настроить парсер-аккаунт

1. Запустите бота
2. Используйте команду `/admin` для входа в админ-панель
3. Добавьте чаты для парсинга через "Управление чатами"

## Запуск

```bash
python bot.py
```

## Использование

### Для пользователей

1. `/start` - Главное меню
2. "Купить доступ" - Покупка подписки (5 TON)
3. "Парсинг" - Запуск поиска NFT (до 10 пользователей)
4. "Профиль" - Статистика использования

### Для админа

1. `/admin` - Админ-панель
2. Статистика - Общая статистика бота
3. Платежи - История платежей
4. Пользователи - Управление пользователями
5. Управление чатами - Добавление/удаление чатов для парсинга
6. Рассылка - Отправка сообщений всем пользователям

## Деплой
