## ⭐ Основные файлы

### 1. `bot.py` (250 строк)
**Что внутри:**
- Главная логика бота
- Команды /start, /menu
- Админ-панель для подключения аккаунта
- Обработка авторизации через номер телефона
- Middleware для внедрения БД

**Запуск:**
```bash
python bot.py
```

---

### 2. `database.py` (350 строк)
**Что внутри:**
- Класс `DatabasePG` для работы с PostgreSQL
- Методы для работы с сессией парсера
- Методы для работы с чатами
- Методы для сохранения найденных пользователей и подарков
- Connection pooling

**Таблицы:**
- `parser_session` - сохранённая сессия Telegram
- `parser_chats` - список чатов
- `parser_users` - найденные пользователи
- `parser_gifts` - найденные подарки
- `parser_scan_state` - состояние сканирования

---

### 3. `ui.py` (50 строк)
**Что внутри:**
- Функции для форматирования сообщений
- `admin_welcome()` - приветствие админа
- `admin_panel()` - админ-панель
- `parser_menu()` - меню парсера
- `esc()` - экранирование HTML

---

### 4. `parsing/telegram_client.py` (300 строк)
**Что внутри:**
- Класс `ParserClient` - Telethon клиент
- `send_code()` - отправка кода на телефон
- `sign_in()` - авторизация с кодом
- `connect()` - подключение через StringSession
- `get_dialogs()` - получение списка чатов
- `iter_participants()` - итератор по участникам
- `get_user_gifts()` - получение NFT через MTProto API

---

### 5. `parsing/scanner.py`
**Что внутри:**
- Класс `ChatScanner` - сканирование чатов
- Логика парсинга участников
- Проверка NFT у пользователей
- Обработка FloodWait
- Статистика сканирования

---

### 6. `parsing/handlers.py`
**Что внутри:**
- Router для aiogram
- Обработчики команд парсера
- Меню выбора чатов
- Запуск/остановка парсинга
- Статистика

---

### 7. `parsing/keyboards.py`
**Что внутри:**
- Inline клавиатуры для парсера
- Кнопки выбора режима (🎁 / 💎)
- Кнопки управления чатами
- Кнопки лимита профилей

---

### 8. `requirements.txt`
**Зависимости:**
```txt
aiogram==3.15.0          # Telegram Bot API
telethon==1.37.0         # MTProto клиент
psycopg2-binary==2.9.10  # PostgreSQL
python-dotenv==1.0.1     # Переменные окружения
aiohttp==3.11.10         # HTTP клиент
```


### 2. Прочитайте документацию
```

DEPLOY_BOTHOST.md → Деплой на bothost.ru
```

### 3. Соберите данные
- BOT_TOKEN от @BotFather
- OWNER_ID от @userinfobot
- TG_API_ID и TG_API_HASH от my.telegram.org

### 4. Задеплойте
- Создайте проект на bothost.ru
- Подключите PostgreSQL
- Добавьте переменные окружения
- Загрузите код
- Запустите!
