## 🌐 Настройка на bothost.ru

### Шаг 1: Получите токен бота

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. **Сохраните токен** (выглядит как `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 2: Узнайте свой Telegram ID

1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Отправьте любое сообщение
3. **Сохраните ваш ID** (например, `123456789`)

### Шаг 3: Получите Telegram API credentials

1. Зайдите на [https://my.telegram.org/apps](https://my.telegram.org/apps)
2. Войдите с помощью вашего номера телефона
3. Создайте приложение:
   - **App title**: Parser Bot
   - **Short name**: parser
   - **Platform**: Other
4. **Сохраните:**
   - `api_id` (например, `12345678`)
   - `api_hash` (например, `abcdef1234567890abcdef1234567890`)

### Шаг 4: Создайте проект на bothost.ru

1. Зайдите на [bothost.ru](https://bothost.ru)
2. Нажмите **Создать проект**
3. Выберите **Python Bot**
4. Укажите имя проекта

### Шаг 5: Подключите PostgreSQL

1. В настройках проекта перейдите в раздел **База данных**
2. Выберите **PostgreSQL**
3. Создайте базу данных
4. **Важно:** После создания bothost.ru автоматически создаст переменную `DATABASE_URL`

### Шаг 6: Добавьте переменные окружения

В разделе **Переменные окружения** добавьте:

| Название | Значение | Пример |
|----------|---------|--------|
| `BOT_TOKEN` | Токен от BotFather | `1234567890:ABCdef...` |
| `OWNER_ID` | Ваш Telegram ID | `123456789` |
| `TG_API_ID` | API ID от my.telegram.org | `12345678` |
| `TG_API_HASH` | API Hash от my.telegram.org | `abcdef123456...` |

**📌 Примечание:** `DATABASE_URL` уже будет создан автоматически при подключении PostgreSQL!

### Шаг 7: Загрузите код

#### Вариант А: Через Git

```bash
git add .
git commit -m "Clean parser only version"
git push bothost master
```

#### Вариант Б: Через веб-интерфейс

1. Архивируйте папку проекта в `.zip`
2. Загрузите через веб-интерфейс bothost.ru

### Шаг 8: Настройте запуск

В настройках проекта укажите команду запуска:

```bash
python bot.py
```

### Шаг 9: Запустите бот

1. Нажмите кнопку **Запустить**
2. Проверьте логи на наличие ошибок
3. Если всё хорошо, увидите сообщение:
   ```
   ✅ Бот запущен и готов к работе
   ```

## 📱 Первое использование

### 1. Подключите аккаунт

1. Откройте бота в Telegram
2. Отправьте `/start`
3. Нажмите **⚙️ Админка**
4. Нажмите **📱 Подключить аккаунт**
5. Введите номер телефона: `+79991234567`
6. Получите код в Telegram
7. Введите код **через пробелы**: `1 2 3 4 5`

**✅ Готово!** Сессия сохранена. При перезапуске бота код вводить не нужно.

### 2. Настройте парсер

1. Нажмите **🔎 Парсер**
2. Нажмите **📂 Мои чаты**
3. Выберите чаты для парсинга (включите нужные)
4. Вернитесь назад

### 3. Запустите парсинг

1. Выберите режим:
   - **🎁 Любые NFT** - все подарки
   - **💎 Только неулучшенные** - только те, что можно улучшить
2. Укажите лимит профилей (рекомендуется 50-200 для начала)
3. Нажмите **▶️ Запустить**

Бот начнёт проверку и будет присылать найденные NFT!

## ⚠️ Частые проблемы и решения

### 1. Ошибка "BOT_TOKEN не указан"
**Решение:** Проверьте что переменная `BOT_TOKEN` добавлена в Environment Variables на bothost.ru

### 2. Ошибка "DATABASE_URL не указан"
**Решение:** 
- Убедитесь что PostgreSQL база данных создана
- Перезапустите проект (bothost.ru должен автоматически добавить переменную)

### 3. Ошибка "Сессия недействительна"
**Решение:** 
- Отключите аккаунт в админке
- Подключите заново с вводом кода

### 4. Бот не отвечает
**Решение:**
- Проверьте что бот запущен (зелёный статус на bothost.ru)
- Проверьте логи на наличие ошибок
- Убедитесь что ваш `OWNER_ID` указан правильно

### 5. Парсер не находит NFT
**Решение:**
- Проверьте что чаты выбраны (включены)
- Увеличьте лимит проверяемых профилей
- Убедитесь что в чатах реально есть пользователи с NFT

### 6. FloodWait ошибка
**Решение:** Это нормально! Telegram ограничивает скорость запросов. Бот автоматически ждёт и продолжает работу.
